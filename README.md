# Análisis de Precipitaciones en Chile
Proyecto integrador para la asignatura de Programación Avanzada (Grupo 3).

## Descripción del Proyecto
Este proyecto implementa una tubería de procesamiento de datos en Python para cargar, validar y analizar registros históricos de precipitaciones en Chile, permitiendo identificar anomalías y patrones climáticos para la gestión hídrica.

## Estructura del Repositorio
- `datos/`: Contiene el archivo CSV con los registros históricos.
- `src/`: Carpeta con el código modular (`carga.py`).
- `reportes/`: Contiene el informe final en formato PDF (`avance_1.pdf`).
- `main.py`: Script principal que ejecuta el flujo del programa.
- `requirements.txt`: Dependencias del proyecto.
